# 每日心情记录工具 MVP

一个简洁直观的心情状态记录工具，帮助用户追踪情绪变化。

## 功能特性

### 📝 心情记录区（主页面）
- 显示当前日期和星期
- 5种基础心情选择，配有可视化 emoji：
  - 😄 开心
  - 😌 平静
  - 😐 一般
  - 😢 低落
  - 😠 愤怒
- 简短文字描述输入框（可选，最多500字）
- 提交按钮，带视觉反馈效果（水波纹）

### 📚 历史记录区
- 按日期倒序显示所有已保存的记录
- 每条记录展示：日期、心情标识、描述摘要
- 点击记录查看完整内容的详情弹窗
- 支持删除单条记录
- 无记录时显示友好的空状态提示

### 🎯 导航功能
- 「今日记录」和「历史记录」标签页切换
- 平滑的过渡动画体验
- 提交记录后自动切换到历史记录页

## 技术特性

### 架构
- 单文件应用（`index.html`），包含所有 HTML、CSS 和 JavaScript
- 无需构建工具和依赖，直接在浏览器中运行

### 数据持久化
- 使用 `localStorage` 保存用户记录
- 页面刷新后数据自动恢复

### 响应式设计
- 完全适配桌面端和移动端
- 在小屏幕上自适应布局调整

### UI/UX
- 温暖的渐变色配色方案
- 平滑的动画和过渡效果
- 清晰的视觉反馈（按钮悬停、点击、表单验证）
- 中文本地化（中文日期格式、提示文字）

## 使用方法

1. 在浏览器中打开 `index.html`
2. 在「今日记录」页面：
   - 点击选择一种心情
   - 输入可选的描述文字
   - 点击「提交记录」保存
3. 在「历史记录」页面：
   - 查看所有已保存的记录
   - 点击任意记录查看完整内容
   - 在弹窗中可以删除该记录
